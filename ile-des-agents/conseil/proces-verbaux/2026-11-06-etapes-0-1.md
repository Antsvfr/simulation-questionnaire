# Conseil — 2026-11-06 — Étapes 0 et 1 (Résidence, registre des opérations)

## Prompt d'origine
Lancer l'étape 0 puis l'étape 1, avec ces précisions : la Résidence est une vraie interface de supervision (projets, avancement, priorité, prochaines actions, problèmes, décisions, instructions au DG) ; les directeurs proposent des missions que le DG classe, le sensible reste au président ; emplacement du département Innovation ; traçabilité complète et vérifiable ; ne pas toucher aux projets externes ; s'arrêter après l'étape 1.

## Avis
- **Clarté** : « racine du dépôt » (déplacer ou dépôt dédié, N3) ? Une instruction au DG est-elle exécutée ou seulement enregistrée (dg.py n'arrive qu'à l'étape 3) ? « Régulièrement », « sensible », « emplacement » à préciser.
- **Exigence** : chaque donnée de la Résidence cite sa source (« non renseigné » sinon) ; journal chaîné par empreintes avec `ile verifier` ; agent identifié par l'`agent_id` du hook ; classement avec score et motif ; test headless (deux missions en parallèle, aucun agent sans exécution). Pièges : faire croire qu'une instruction est exécutée ; serveur qui accepte un POST sans jeton ou sert le journal en clair. Ajout : un script unique qui prouve chaque critère (PASS/FAIL/NOT TESTED).
- **Stratégie** : l'étape 0 rapporte tout de suite ; la Résidence doit s'ouvrir sur les décisions qui débloquent vraiment (PR #26, accès LexNote, git UPSA). SQLite et multi-missions prématurés ; Innovation = dossier + ligne au registre.

## Prompt final
Étape 0 puis 1, arrêt pour validation. Résidence = page de supervision sourcée ; instruction enregistrée, présentée au DG à sa prochaine session (hook SessionStart), jamais présentée comme exécutée. Journal JSONL chaîné SHA-256, source unique ; projections recalculées ; **pas de SQLite** (ajouté si le volume l'exige). Serveur : jeton + origine + fichiers internes non servis. Île active à la racine sans déménager le dépôt. Directeurs proposent via `/revue`, DG classe par formule publique. Innovation : dossier, registre, chantier 3D. Script de preuves.
