# Conseil — 2026-11-06 — Trois grosses maisons (UPSA, REV-EM, LexNote)

## Prompt d'origine
Garder les 3 principaux projets sur l'île : créer 3 grosses maisons, une par projet, avec leurs différentes branches, pour améliorer leur structure et faire avancer ce qui est commencé.

## Avis
- **Clarté** : « maisons », « branches », « garder » sont ambigus. Le code d'UPSA est sur le Mac, le zip REV-EM diffère de `main`, LexNote n'est que sur GitHub. Il faut recopier les règles strictes de chaque projet.
- **Exigence** : chaque maison porte son état réel (sources, branche, PR, règles) sans rien simuler ni exagérer l'avancement. Pièges : maisons décoratives, règles violées (main, push, secrets).
- **Stratégie** : le but est un point d'entrée unique pour reprendre les 3 projets sans perdre leur état. Raccourci : maisons « tableaux de bord » sans code importé. LexNote est probablement le plus urgent (5 PR empilées).

## Prompt final
Construis 3 grosses maisons (UPSA Sales Pilot, REV-EM, LexNote) avec CLAUDE.md propre (règles du projet recopiées), journal, branches réelles relevées sur GitHub, état des lieux vérifié / non vérifié, agent chef dédié et bâtiment agrandi dans le village. Aucun code modifié ni importé. Signale les écarts entre sources au lieu de les trancher.
