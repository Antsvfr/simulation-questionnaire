# Dépôt de l'Île des Agents

L'île vit dans `ile-des-agents/`. Sa constitution s'applique à toute session ouverte dans ce dépôt :

@ile-des-agents/CLAUDE.md

**Chemins.** Tous les chemins cités par la constitution (`registre.json`, `maisons/`, `operations/`, `forge/`…) sont relatifs à `ile-des-agents/`. Les agents et commandes de l'île sont disponibles ici par les liens `.claude/agents` et `.claude/commands` ; les hooks par `.claude/settings.json` (qui pointe vers `ile-des-agents/`).
